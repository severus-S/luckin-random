# 取X 更新要求

- 面向用户交付每次更新时，将 app.json 的版本末位和 buildNumber 分别加 1。构建重试保持同一发布版本，构建与下载后核对这两个版本字段。
- Bundle ID 固定为 com.sjx13.ios.qux。现有快照文件、AppStorage key 和 WebKit 默认数据存储维持可覆盖升级的数据兼容性。模型调整必须支持已保存数据。
- 交付经过构建与校验的未签名 IPA，用户使用相同 Apple ID、签名身份和有效 Bundle ID 直接覆盖安装。更新操作使用覆盖路径，指导用户保留已安装 App。
- 维持 iOS 27 原生液态玻璃与 APK 原图标。按根目录工作流复用瑞幸公开仓库的 codex/qux-ios-build 分支。
- 真机登录和覆盖后数据保留需要用户实测反馈，记录验证范围。
