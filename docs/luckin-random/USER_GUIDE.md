# 手机使用步骤

用户于 2026-11-05 明确：瑞幸 Token 在手机 App 内填写。以下是真实查询模式的配置路径；离线模拟不需要 Token。

## 首次配置

1. 用户在电脑 Sideloadly 中完成 IPA 签名安装，再在手机打开“瑞幸随机咖啡”。安装成功前，以 BUILD.md 中的验收状态为准。
2. 手机 App → 设置 → 运行模式，启用“连接 HTTPS 后端”，填写部署好的 HTTPS 地址及后端配对密钥，点击“保存密钥并验证连接”。后端部署目标尚需单独确定。
3. 手机 App → 设置 → 瑞幸账号授权 → “打开瑞幸官方授权平台”。在手机浏览器完成官方登录及 Token 获取。
4. 回到手机 App，在“在手机粘贴官方 MCP Token”中填写，点击“验证并加密保存到后端”。无须在电脑配置环境变量，也不向开发者发送 Token。
5. 验证成功后，Token 输入框清空；设置页显示授权状态。失效时仍在手机更新；删除后端令牌会停止真实下单，官方撤销需在官方平台完成。
6. 选择门店，搜索饮品、设置规格并加入咖啡池，设置消费限额，先使用“只抽取并预览价格”验收。

手机输入经已配对 HTTPS 连接发送到后端，后端先执行只读工具发现，成功后才加密保存。App 配置备份不包含 Token；Token 不写入 Git 或普通日志。

## 当前限制

真实下单默认关闭，正式接口与支付未验收前入口保持锁定。填写 Token 不等于授权真实下单或付款。
Token 输入功能已编译入 App，真实瑞幸授权尚未验收。
现阶段官方 Token 获取页面能否在目标手机顺利复制、实际菜单与支付路径，都需要用户真机验证。
自动任务需要持续运行的后端；目前通知为站内通知箱，远程锁屏通知尚未接入。
